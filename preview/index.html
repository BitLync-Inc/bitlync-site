Guides

From key to first write.

Seeded sandbox tenants only. Responses include top-level sandbox: true.

01 · Quickstart

Start the sandbox and copy a key

Keys look like blk_…. Send them as X-API-Key.

bashlocal
# from the repo
python -m sandbox.serve --print-key

export BITLYNC_BASE=  # your host when you have one
export BITLYNC_KEY='blk_…'
export TENANT=sandbox-mainstreet

Seeded tenants: sandbox-mainstreet is healthy (ConnectWise PSA + NinjaOne RMM + ScalePad GRC fixtures). sandbox-northline is degraded (HaloPSA missing ServiceDesk scope). These are fixture-backed sandbox tenants, not production hosts.

02 · First call

Read tickets, then write once

GET seeded tickets. POST a ticket for Brightside Pediatrics with dry_run true, then false, same idempotency_key. Replay marks idempotent_replay. Then GET audit.

curl$BITLYNC_BASE · public host coming
curl -sS "$BITLYNC_BASE/tenants/$TENANT/tickets" \
  -H "X-API-Key: $BITLYNC_KEY"

curl -sS -X POST "$BITLYNC_BASE/tenants/$TENANT/tickets" \
  -H "X-API-Key: $BITLYNC_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "company_name": "Brightside Pediatrics",
    "summary": "Quarterly vCIO review, MFA coverage gap",
    "priority": "medium",
    "dry_run": true,
    "idempotency_key": "quickstart-ticket-001"
  }'

Repeat the POST with dry_run: false, then the same body again. GET /tenants/$TENANT/audit to see preview, commit, and replay.

03 · Connect an MSP

The MSP pastes their own keys

The ISV does not paste MSP credentials. The MSP pastes PSA and RMM keys in the MSP portal. The ISV never holds those creds. A hosted portal is coming. There is no public connect URL to publish yet.

04 · Sandbox reset

Clear audit and re-sync fixtures

POST /sandbox/reset with {"tenant_id":"sandbox-mainstreet"}. Clears audit, re-syncs fixtures, writes one sandbox_reset event. Production tenants return 422 request_invalid.

curlsandbox tenants only
curl -sS -X POST "$BITLYNC_BASE/sandbox/reset" \
  -H "X-API-Key: $BITLYNC_KEY" \
  -H "Content-Type: application/json" \
  -d '{"tenant_id":"sandbox-mainstreet"}'

In-repo path clients/python. Import bitlync_client. Generated. Not on a public index.
