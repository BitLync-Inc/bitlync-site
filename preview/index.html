Quickstart

From key to first write.

Seeded tenants are fixture-backed only. Use $BITLYNC_BASE as the host placeholder.

Keys look like blk_…. Send them as X-API-Key.

auth
X-API-Key: blk_…

tenant_id: sandbox-mainstreet
# or sandbox-northline

sandbox-mainstreet and sandbox-northline are sandbox fixtures (PSA and RMM seed data). They are not production tenants.

GET tickets

GET tickets
curl -s "$BITLYNC_BASE/tenants/sandbox-mainstreet/tickets" \
  -H "X-API-Key: $BITLYNC_KEY"

POST tickets

dry_run defaults true. Commit by sending dry_run: false plus an idempotency_key. The same key on a retry returns idempotent_replay.

POST /tenants/{tenant_id}/tickets

Header X-API-Key: blk_….

Try it out · Coming

body · dry_run then commit

{
"summary": "Printer offline",
"dry_run": true,
"idempotency_key": "ticket-1"
}
then commit
{ "dry_run": false, "idempotency_key": "ticket-1" }

GET audit

GET audit
curl -s "$BITLYNC_BASE/tenants/sandbox-mainstreet/audit" \
  -H "X-API-Key: $BITLYNC_KEY"

Sandbox reset

POST /sandbox/reset with {"tenant_id":"sandbox-mainstreet"}. Clears audit, re-syncs fixtures, writes one sandbox_reset event. Production tenants return 422 request_invalid.

POST /sandbox/reset
curl -s -X POST "$BITLYNC_BASE/sandbox/reset" \
  -H "X-API-Key: $BITLYNC_KEY" \
  -H "Content-Type: application/json" \
  -d '{"tenant_id":"sandbox-mainstreet"}'

Use cases

What you can build.

Six paths. Honest labels. Device inventory is not a use case.

1. Alert to ticket live

A finding or alert becomes a ticket. Incident and approval sit on this same path. Do not split them.

2. Map customers live

Sure match auto-maps. A leftover PSA company is an ask. Ambiguous stays unmatched. The create-into-ISV hop is Coming.

3. Billing reconciliation Coming

Agreement-shaped billing later. There is no GET /agreements today.

4. Agent deploy

POST /tenants/{tenant_id}/deployments.

5. Time on the ticket later

Time entries exist in schema. Mapping is still next-slice. No route.

6. Close with evidence later

Close a ticket with the work attached. Not shipped.
